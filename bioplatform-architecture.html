BioPlatform 系统架构

Spring Boot 3.4.2 分层后端 · Vue3 双前端 · MySQL/Redis · AI Agent 多智能体 · 流水线 Worker 分布式执行

后端分层 (bioplatform-springboot)

  • • 安全层: JWT Filter + Spring Security + OperLogAspect AOP + 全局异常
  • • Controller: admin 15 个 + front 6 个，共 21 个 REST 控制器
  • • Service: 16 个业务服务（Agent/流水线/项目/文件/系统配置…）
  • • 持久层: MyBatis 3.0.4 + PageHelper，19 Mapper + XML + 19 entity
  • • 配置: system_configs KV 表，API Key AES-GCM 加密 (ENC:)，前端 mask 展示

AI 与执行链路

  • • AgentOrchestrator 正则意图识别 → 路由到 DataAnalysis/Pipeline/QA 三个智能体
  • • LLMClient 经 OkHttp 调 OpenAI 兼容接口，SSE 流式返回，SseEmitter 推前端
  • • AgentToolExecutor 6 个工具（Shell/DB/FileInfo/FormatInfo/PipelineSearch/CreateSkill）
  • • 流水线: PipelineTaskDispatcher 派发到 Worker，30s 健康检查 + 状态轮询
  • • 存储双策略: SharedStorageStrategy / WorkerStorageStrategy 屏蔽差异

部署拓扑

  • • nginx-proxy 统一 HTTPS，/ → front/admin 静态，/api /ws → backend:8080
  • • 生产: 阿里云 ECS docker-compose-remote.yml，加入 blog_net 与博客共用基础设施
  • • 本地: docker-compose.yml 自带 MySQL 8 / Redis 7（3308 / 6380 端口）
  • • 发布链路: 本地构建镜像 → docker save/load → force-recreate（禁远程 build）
  • • Worker 可独立扩展为多计算节点，注册于 compute_nodes 表
